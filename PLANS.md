# Plan template

Copy this template into docs/plans/<task>.md for complex changes.

## Problem and desired behavior
Describe a concrete before/after example.

## Scope
Affected files, public contracts, and explicit exclusions.

## Steps
- [ ] Inspect implementation and baseline checks
- [ ] Implement the smallest coherent change
- [ ] Add behavior and regression tests
- [ ] Run verification and review diff

## Acceptance criteria
Observable outcomes, error paths and compatibility requirements.

## Risks and decisions
Alternatives, migration implications, approvals already obtained.

## Evidence
Commands, exit codes, findings, fixes, and checks not run.

## Handoff
Remaining work and reproduction instructions.
